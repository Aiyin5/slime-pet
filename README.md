# 史莱姆桌面宠物（Slime Pet）

一只薄荷绿的大史莱姆常驻桌面，头顶气泡显示当前待办，到点会弹跳提醒；
任务通过浏览器里的本地后台管理页面维护。数据全部保存在本机，不联网。

## 功能

- **桌面史莱姆**：果冻质感，呼吸、眨眼、蠕动；透明背景、窗口置顶
- **待办气泡**：显示任务名称、时间、状态与剩余时间，角标标明浏览位置
- **鼠标交互**：
  - 左键单击史莱姆 → 切换到下一个待办（同时关闭当前提醒）
  - 左键双击史莱姆 → 当前任务标记完成（史莱姆开心跳一下）
  - 拖动 → 移动位置
  - 右键 → 打开管理页面 / 暂停提醒 / 隐藏 / 退出
- **到点提醒**（弹跳 + 气泡，无声音无系统通知）：
  - 开始前 N 分钟（可配，默认 5）：小幅弹跳、身体泛黄
  - 到达开始时间：剧烈弹跳、身体泛橙
  - 到达结束时间：剧烈弹跳，提示双击完成
- **后台管理页面**：任务的新增、编辑、删除、完成，支持「今天 / 全部」筛选
- 一次性任务，**支持跨天**（结束时间可在次日或更晚）

## 运行

依赖已安装在项目内 `libs` 目录，直接运行：

```powershell
python main.py
```

启动后史莱姆出现在屏幕右下角；首次启动会自动打开管理页面。
之后可右键史莱姆 →「打开任务管理页面」，或访问 http://127.0.0.1:17821/

如需自行安装依赖：`pip install -r requirements.txt`

## 目录结构

```
slime-pet/
├── main.py               # 入口：Qt 主线程 + FastAPI 后台线程
├── core/
│   ├── models.py         # 任务模型、状态枚举、时间解析
│   ├── database.py       # SQLite 数据访问（tasks 表）
│   └── scheduler.py      # 提醒调度引擎（5 秒轮询）
├── pet/
│   ├── slime_render.py   # 史莱姆程序化绘制与动画
│   └── slime_widget.py   # 透明窗口、气泡、交互、托盘
├── server/
│   └── api.py            # FastAPI 接口 + 静态页面托管
├── web/                  # 后台管理页面（HTML/CSS/JS）
├── data/tasks.db         # SQLite 数据（运行后生成）
└── libs/                 # 项目内依赖
```

## 说明

- 后台仅监听 `127.0.0.1`，不设密码，外部设备无法访问
- 不含开机自启
- 关闭窗口后程序仍在系统托盘运行，托盘右键可退出
